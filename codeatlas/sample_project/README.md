# Sample Project — Rental Catalogue REST API

A small, self-contained Spring Boot REST application bundled with CodeAtlas so
the analyser has something to run against out of the box. It mirrors the
layered shape of the reference project
(`https://github.com/codejsha/spring-rest-sakila`): a controller layer, a
service layer, a JPA entity, and a Spring Data repository.

Replace this folder with a clone of any real repository to analyse it instead.
